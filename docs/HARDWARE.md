# Обладнання та HID

## Пристрій

Передавач: RadioMaster TX12, підключений до комп'ютера через USB у режимі USB Joystick/HID.

Ідентифікатори, отримані під час тестування:
- Manufacturer: `OpenTX`;
- Product: `Radiomaster TX12 Joystick`;
- VID: `0x1209`;
- PID: `0x4F54`.

## Перевірена послідовність

Під час тесту кнопок отримано такі значення перших трьох байтів:

```text
00 00 00
01 00 00
00 00 00
02 00 00
00 00 00
01 00 00
03 00 00
01 00 00
00 00 00
```

Це підтвердило маску кнопок у першому байті:
- біт 0 відповідає A;
- біт 1 відповідає D.

## Підключення

1. Під'єднайте TX12 до Mac через USB.
2. Увімкніть режим USB Joystick/HID на передавачі, якщо він не активується автоматично.
3. Переконайтеся, що macOS бачить пристрій за допомогою:
   ```bash
   python src/tx12_hid_test.py
   ```

Точна поведінка USB-режиму може залежати від прошивки та конфігурації передавача.
