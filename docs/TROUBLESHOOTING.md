# Діагностика та усунення проблем

## TX12 not found

1. Перевірте USB-кабель: він має передавати дані, а не лише живлення.
2. Перевірте USB-режим передавача.
3. Запустіть:
   ```bash
   python src/tx12_hid_test.py
   ```
4. Переконайтеся, що у виводі є VID `0x1209` та PID `0x4f54`.

## Pygame не бачить джойстик

`tx12_test.py` — додатковий тест через Pygame. У попередньому тестуванні Pygame не виявив джойстик, хоча пряме читання через hidapi працювало. Тому для основної програми використовується `hidapi`, а не Pygame.

## Кнопки не показують очікуваних значень

Запустіть:

```bash
python src/tx12_buttons.py
```

Перевірте:
- A дає перший байт `01`;
- D дає перший байт `02`;
- одночасне натискання дає `03`;
- відпускання повертає `00`.

Якщо значення відрізняються, не змінюйте маску навмання: спочатку збережіть повний HID-звіт через `tx12_read.py`.

## Chrome error або не відбувається керування YouTube

1. Переконайтеся, що відкрито Google Chrome, а не інший браузер.
2. Переконайтеся, що хоча б одна вкладка має адресу з `youtube.com`.
3. Увімкніть **View → Developer → Allow JavaScript from Apple Events**.
4. Перевірте системний дозвіл Terminal/iTerm на керування Google Chrome у **System Settings → Privacy & Security → Automation**.
5. Запустіть програму з Terminal і перегляньте повідомлення про помилки.

## Перемотування не працює

Переконайтеся, що у вкладці YouTube відтворюється відео з HTML5-плеєром. Скрипт шукає елемент `video` і змінює його `currentTime`.

## Зібрати сирі HID-дані

```bash
python src/tx12_read.py
```

Скрипт читає звіти протягом 20 секунд і виводить змінені значення у шістнадцятковому форматі.

## Важливо про статус тестування

Перевірка HID-ідентифікаторів і кнопкової маски виконувалася на реальному TX12. Повний наскрізний сценарій (TX12 → Python → AppleScript → Chrome → YouTube) у цьому репозиторії ще не позначений як підтверджений тест. Перед щоденним використанням перевірте короткі натискання, довге утримання та поведінку при одночасному натисканні.
