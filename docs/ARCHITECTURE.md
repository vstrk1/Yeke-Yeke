# Архітектура

## Загальна схема

```text
RadioMaster TX12
      │ USB HID
      ▼
macOS / hidapi
      │ HID report
      ▼
tx12_youtube.py
      │ AppleScript (osascript)
      ▼
Google Chrome
      │ JavaScript
      ▼
YouTube HTML5 player
```

## Ідентифікація HID-пристрою

У коді використовуються:
- Vendor ID: `0x1209`
- Product ID: `0x4F54`

У десятковому форматі це 4617 та 20308 відповідно.

Пристрій визначається через `hid.enumerate()`. Програма бере унікальні HID-шляхи, відкриває перший знайдений інтерфейс і читає звіти через `hid.device()`.

## Кнопкова маска

За результатами фактичного тесту першого байта звіту:
- `0x00` — жодна з двох кнопок не натиснута;
- `0x01` — A;
- `0x02` — D;
- `0x03` — A та D одночасно.

Основна програма використовує вираз `data[0] & 0x03`.

## Розпізнавання натискання

Параметри:
- `HOLD_THRESHOLD = 0.45` секунди;
- `SEEK_INTERVAL = 0.5` секунди;
- `SEEK_SECONDS = 5` секунд.

Коротка дія виконується після відпускання кнопки. Після досягнення порога утримання програма періодично змінює `video.currentTime`.

## Керування браузером

Python запускає `osascript` і передає AppleScript. Скрипт перебирає вікна та вкладки Google Chrome, знаходить URL із `youtube.com` і виконує JavaScript у цій вкладці.

Використані елементи YouTube:
- `.ytp-prev-button` — попереднє відео;
- `.ytp-next-button` — наступне відео;
- HTML5 `video.currentTime` — перемотування.

Програма не використовує YouTube API та не керує іншими браузерами.

## Файли

- `tx12_youtube.py` — основний цикл HID та керування YouTube.
- `tx12_hid_test.py` — пошук HID-пристрою.
- `tx12_read.py` — читання сирих HID-звітів.
- `tx12_buttons.py` — відображення змін перших трьох байтів.
- `tx12_test.py` — альтернативна діагностика через Pygame.
